# Personal-INI-Edits-for-Mental-Omega-3.3.6
A repository containing most of my whacky INI edits for MO 3.3.6. An unofficial modification for Command &amp; Conquer Red Alert 2 Yuri's Revenge.

All files are mission-specific INI edits that are meant to be applied via Notepad++.

You're free to take parts of my edits and apply it to your mission's INI settings however you see fit, I only ask that you credit me and disclose the source which is this repository.
